# Repository Instructions

## Public Repository Hygiene

- The source code is MIT licensed.
- The imported StarScout/Zenodo dataset and generated database dumps are not
  committed and are not relicensed by this repository.
- Real `.env` files, generated extension packages, `mongodb.zip`, restored
  MongoDB files, and Postgres dumps must stay out of git.
- Never commit real credentials. Use `.env.example` files as safe templates only.
- Do not distribute imported Postgres databases.

## Product Language

- Use "suspected non-legit stars."
- Do not present results as definitive proof that stars, users, or repositories
  are fake.
- Include the privacy notice and GitHub Issues support link in every beta
  announcement.
