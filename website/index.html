Dev-loaded beta

See StarScout-derived star integrity signals while browsing GitHub.

StarScout Star Integrity adds a small badge to public GitHub repository pages with aggregate suspected non-legit star signals. It is a heuristic signal, not proof that any star, account, or repository is fake.

Get support Read privacy notice

What it does

  • Detects public github.com/{owner}/{repo} pages.
  • Sends only the public owner/repo identifier to the API.
  • Shows aggregate suspected-star metrics, warnings, cutoff date, and attribution.
  • Never exposes suspected actor-level stargazer identities.

Install the beta

This beta is not published in the Chrome Web Store. Install it only if you trust the source and are comfortable loading an unpacked extension.

  1. Download the beta zip from the project release.
  2. Unzip it locally.
  3. Open chrome://extensions.
  4. Enable Developer mode.
  5. Choose Load unpacked and select the unzipped directory.

Limitations

  • Public GitHub repositories only.
  • No private repositories or GitHub Enterprise Server.
  • Missing data means not analyzed, not zero suspected stars.
  • Dev-loaded packages do not auto-update.
